# Fire Route Navigator

Crea una aplicación web profesional para rutas de camiones de bomberos.



La aplicación debe tener:



- Diseño moderno oscuro y profesional

- Un mapa grande usando OpenStreetMap

- Un selector de vehículos

- Un buscador de direcciones

- Un botón "Calcular Ruta"



Los vehículos deben tener:

- altura

- anchura

- peso

- longitud



La aplicación debe estar preparada para evitar calles estrechas y restricciones de tamaño.



La interfaz debe estar optimizada para tablets usadas en vehículos de emergencia.



El diseño debe ser simple, táctil y profesional.
